# Zerick Syahputra - Portfolio Website

> Personal portfolio website of **Zerick Syahputra**, an IoT & Embedded Systems Developer and Informatics student at Universitas Amikom Yogyakarta.

## 🚀 Fitur Unggulan
- **Tema Gelap Luar Angkasa (Dark Space Theme)** dengan pendaran neon biru (*neon blue glow*).
- **Background Interaktif**: Animasi bintang multi-layer (*interactive HTML5 space canvas*) yang merespons pergerakan mouse dan klik meteor.
- **Floating Glassmorphism Navbar**: Navbar melayang di tengah atas dengan efek blur dan *scrollspy* penanda posisi aktif.
- **Typewriter Effect**: Teks mesin ketik otomatis di hero header.
- **Core Tech Stack**: 5 keahlian utama dalam kotak persegi simetris (Arduino, ESP32, C++, Bahasa C, Python).
- **Horizontal Projects Carousel**: Galeri karya nyata yang dapat digeser (drag & swipe) dengan 5 proyek unggulan.
- **Retro Space Impact Game Simulation**: Mini game konsol klasik piksel layar LCD hijau bertenaga Web Audio 8-bit sound synthesizer.
- **Galeri Sertifikat Resmi**: 6 sertifikat kejuaraan dan asistensi praktikum lengkap dengan pembesar gambar (*lightbox modal*).
- **Integrasi Kontak Lengkap**: WhatsApp langsung, LinkedIn, Instagram, GitHub, email, dan toko modul edukasi di [Lynk.id](https://lynk.id/rakitproject).

## 🛠️ Teknologi yang Digunakan
- **HTML5 & Semantic Markup**
- **Modern CSS3** (CSS Custom Properties, Flexbox, CSS Grid, Glassmorphism Backdrop Blur, KaTeX & Keyframes Animation)
- **Vanilla JavaScript (ES6+)**
- **HTML5 Canvas API & Web Audio API**
- **Font Awesome 6 & Google Fonts** (Space Grotesk, Plus Jakarta Sans, JetBrains Mono)
